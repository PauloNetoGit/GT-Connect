Política de Privacidade do app Pedal Ponte

Última atualização: novembro de 2026

O Pedal Ponte liga um pedal MIDI a uma pedaleira BOSS GT-1, usando o celular como ponte. Esta política explica como o app trata informações.

Dados coletados

O app não coleta, não envia e não compartilha dados pessoais. Ele não tem cadastro, anúncios, rastreamento nem análise de uso, e não se conecta à internet.

Dados guardados no aparelho

As configurações dos botões do pedal ficam salvas somente no seu celular. Elas são apagadas quando você desinstala o app ou limpa os dados dele.

Permissões

  • Bluetooth (dispositivos próximos): usado apenas para encontrar o pedal MIDI e se conectar a ele. O app não usa o Bluetooth para descobrir sua localização.
  • USB: usado apenas para se comunicar com a pedaleira ligada pelo cabo.
  • Localização (somente Android 11 ou anterior): o próprio Android exige essa permissão para buscar aparelhos Bluetooth. O app não lê nem guarda sua localização.

Crianças

O app não é voltado a crianças e não coleta dados de ninguém.
